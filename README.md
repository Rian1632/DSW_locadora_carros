# Rota Prime — versão simplificada

Site acadêmico fictício de locadora de carros feito apenas com **HTML e CSS**.

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Use o menu para acessar as outras quatro páginas.

## Pastas

- `index.html`: início.
- `pages/`: veículos, serviços, sobre e reserva.
- `assets/css/style.css`: estilos de todas as páginas.
- `assets/images/`: imagens dos carros.

## Importante

O formulário é apenas visual. Nesta etapa, não há JavaScript, backend, banco de dados ou envio real de reservas.
